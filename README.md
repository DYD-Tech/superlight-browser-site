# Superlight Browser

Windows 上的全面屏极简浏览器：整窗是网页，悬浮球管其余的事。

## 下载

打开本站首页，点 **下载 Windows 安装包**（MSI），或到 [Releases](https://github.com/DYD-Tech/superlight-browser-site/releases) 取最新版。

- 系统：Windows 10 / 11（64 位）
- 需要已安装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（多数电脑已有）

## 更新

装好后可在应用内检查更新。新版本会发布到本仓库的 Releases。

## 说明

- 无扩展商店、无账号云同步、无信息流
- 浏览数据保存在本机；卸载时默认清除本程序留下的数据

问题与反馈请通过你获取本软件的渠道联系作者。
